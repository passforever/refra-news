# 2026-05-20 工作日志

## 耐火材料资讯网站开发

完成了一个完整的耐火材料资讯聚合平台，技术栈 React + TypeScript + Vite + Tailwind CSS + shadcn/ui。

### 核心功能
- 8大行业精准筛选（钢铁、水泥、玻璃、有色、石化、陶瓷、电力、碳素）
- 7类资讯分类（推荐、行业新闻、市场行情、技术前沿、企业动态、政策法规、展会活动）
- 原料行情滚动 Ticker（镁砂、刚玉、碳化硅等）
- 全文搜索、行业联动过滤
- Python 爬虫脚本 + GitHub Actions 每日 02:00 北京时间自动爬取

### 文件结构
- `app/` - React 前端（Vite 构建，产出 dist/）
- `app/crawler/crawler.py` - Python 爬虫
- `.github/workflows/crawler.yml` - GitHub Actions 自动化
- `README.md` - 完整部署说明
- `.gitignore` - Git 忽略配置

### 构建踩坑
- tailwind.config.js 在 `"type":"module"` 项目中需用 ESM export default，不能用 module.exports
- TypeScript verbatimModuleSyntax 要求类型导入必须用 `import type`

### 部署方式
1. git init & push 到 GitHub
2. Settings → Pages → 选 gh-pages 分支
3. GitHub Actions 自动爬取+构建+部署
